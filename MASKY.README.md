# User Greeting Program
This program asks the user for their name and age, then displays a simple greeting message using the provided information.

# Features
Asks the user to enter their name
Asks the user to enter their age
Prints a personalized greeting using both values

# How to use
Run the program and enter your name and age when prompted.
The program will then display a message showing the collected information.




# Learning Purpose
This project was created as part of my backend engineering practice.
The goal was to improve my skills in Python, user input handling, string formatting, and basic variables.
